# Vuosikalenteri

**Yhtiön tilikausi:** `config/yritys.yaml` → `tilikausi`. Tilikauden
määräajat lasketaan tilikauden lopusta (T). ALV-kausi on eri asia, ks.
`arvonlisavero.md`.

Alla oleva taulukko "Vuoden kulku" on kalenterivuosi-tilikaudelle
(T = 31.12.). Jos yhtiön tilikausi on muu, laske päivät uudelleen samoilla
säännöillä (T + 4 kk, T + 6 kk, T + 8 kk) ja lisää yhtiön oma taulukko tähän.

## Jatkuvat

| Milloin | Mitä | Viite |
|---|---|---|
| Laskun lähettämisen jälkeen | Lasku arkistoon, myyntisaaminen kirjataan | KPL 2:3 |
| Kuukausittain, viimeistään 4 kk kuluttua | Tositteet ja tiliote kirjattu, pankki täsmäytetty | KPL 2:4 |
| Ison laskun jälkeen | Ennakkoveron tarkistus OmaVerossa | – |
| **Joka kuun 12.** | ALV-ilmoitus ja maksu toissa kuukaudelta, myös nollailmoitus (jos kausi = kuukausi). Muistutus kuun 3. päivänä | AVL, `arvonlisavero.md` |
| Laskutettaessa | Verokannan valinta: esiintymispalkkio vai muu palvelu | AVL 45 §, `arvonlisavero.md` |

## Vuoden kulku (tilikausi 1.1.–31.12.)

| Päivä | Mitä | Viite |
|---|---|---|
| 31.12. (T) | Tilikausi päättyy. Saamiset ja velat inventoidaan | KPL 3 luku |
| tammi–helmi | Tilinpäätös ja tase-erittelyt laaditaan | KPL 3:1 |
| **helmikuun loppu** | ALV-vuosi-ilmoitus ja maksu (jos kausi = vuosi) `⚠ TARKISTA` | AVL |
| tammikuu | Tilintarkastusrajojen tarkistus kahdelta viimeiseltä tilikaudelta | TilintL 2:2 |
| **30.4. (T + 4 kk)** | Tilinpäätös laadittu ja allekirjoitettu | KPL 3:7 |
| **30.4. (T + 4 kk)** | Veroilmoitus 6B OmaVerossa `⚠ TARKISTA` | VML |
| T + 4 kk | Mahdollinen täydennysmaksu `⚠ TARKISTA` päivä | – |
| **30.6. (T + 6 kk)** | Varsinainen yhtiökokous / osakkaan päätös: vahvistus, osinko, vastuuvapaus | OYL 5:3 |
| osingon jälkeen | Osingon maksu, ennakonpidätys, ilmoitus Verohallinnolle | TVL 33 b § |
| **31.8. (T + 8 kk)** | Tilinpäätös rekisteröity PRH:een (myös Verohallinnon kautta) | KPL 3:9 |
| syksy | Verotuspäätös, jäännösvero tai palautus | – |

## Muutokset, joista ilmoitetaan erikseen

- Hallituksen, osoitteen, toimialan tai yhtiöjärjestyksen muutos → PRH (YTJ).
- Tosiasialliset edunsaajat → PRH, kun ne muuttuvat.
- ALV-rekisteröinti tai sen päättyminen → YTJ.
