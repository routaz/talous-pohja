# Osakeyhtiölaki (OYL 624/2006)

## Päätöksenteko yhden osakkaan yhtiössä

| Sääntö | Viite |
|---|---|
| Osakkeenomistajat käyttävät päätösvaltaa yhtiökokouksessa | OYL 5:1 |
| Osakkaat voivat yksimielisesti päättää asian **ilman kokousta**. Päätös kirjataan, päivätään, numeroidaan ja allekirjoitetaan | OYL 5:1 |
| Varsinainen yhtiökokous pidetään 6 kk:n kuluessa tilikauden päättymisestä | OYL 5:3 |
| Varsinainen yhtiökokous päättää: tilinpäätöksen vahvistamisesta, voiton käyttämisestä, vastuuvapaudesta, hallituksen valinnasta (tarvittaessa) | OYL 5:3 |
| Jos hallituksessa on alle kolme jäsentä, valitaan vähintään yksi varajäsen | OYL 6:8 |
| Osakasluettelo pidetään ajan tasalla | OYL 3 luku |

Käytännössä yksi allekirjoitettu **osakkaan päätös** vuodessa riittää. Siinä
vahvistetaan tilinpäätös, päätetään osingosta ja myönnetään vastuuvapaus.
Päätös arkistoidaan kansioon `arkisto/paatokset/`. Pohja tehdään
myöhemmin `year-end`-skilliin.

## Varojen jakaminen

| Sääntö | Viite |
|---|---|
| Varoja jaetaan vain lain mukaisesti: osinko, vapaan oman pääoman rahaston jako, osakepääoman alentaminen, omien osakkeiden hankinta, purkaminen | OYL 13:1 |
| Muu liiketoimi, joka heikentää yhtiön taloudellista asemaa ilman liiketaloudellista perustetta, on laitonta varojenjakoa | OYL 13:1 |
| **Maksukykytesti**: varoja ei saa jakaa, jos jakopäätöstä tehtäessä tiedetään tai pitäisi tietää, että yhtiö on maksukyvytön tai jako johtaa maksukyvyttömyyteen | OYL 13:2 |
| **Tasetesti**: jaetaan vain jakokelpoisista varoista eli vapaasta omasta pääomasta. Vähennyksenä tilinpäätöksen jälkeiset olennaiset muutokset | OYL 13:5 |
| Osingonjako perustuu **vahvistettuun tilinpäätökseen**. Yhtiökokous voi myös valtuuttaa hallituksen päättämään osingosta | OYL 13:6 |
| Laittomasti saatu jako palautetaan korkoineen | OYL 13:4 |
| Laina osakkaalle vain jakokelpoisista varoista. Merkitään liitetietoihin | OYL 13:10 |
| Jos oma pääoma on negatiivinen, hallitus tekee siitä viipymättä rekisteri-ilmoituksen. Kun oma pääoma on taas positiivinen, merkinnän voi poistaa ilmoituksella. `⚠ TARKISTA` | OYL 20:23 |

### Mitä tämä tarkoittaa "nosto vuoden lopuksi" -mallissa

- **Kuluvan tilikauden voittoa ei voi nostaa osinkona ennen kuin tilinpäätös on
  laadittu ja vahvistettu.** Tilikaudella 2026 tienattu raha voidaan jakaa
  osinkona aikaisintaan vuoden 2027 alussa, kun tilinpäätös 2026 on vahvistettu.
- Vuoden aikana voi jakaa osinkoa *edellisen* vahvistetun tilinpäätöksen
  vapaasta omasta pääomasta ylimääräisellä päätöksellä. Silloin huomioidaan
  tilinpäätöksen jälkeiset olennaiset muutokset (OYL 13:5).
- Jokaiseen osingonmaksuun tarvitaan päivätty ja allekirjoitettu päätös
  arkistoon. Lisäksi osingonmaksu ilmoitetaan tulorekisteriin tai
  Verohallinnolle (ks. `osinko-ja-nostot.md`).
